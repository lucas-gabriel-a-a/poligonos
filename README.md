# 🧮 Calculadora Universal de Polígonos Regulares

Este script em Python calcula todas as propriedades métricas e ângulos de um **polígono regular** de $n$ lados a partir de **apenas uma variável conhecida** (como lado, área, apótema, raio, etc.).

## ✨ Funcionalidades

O script calcula automaticamente:
- 📏 **Lado** do polígono
- 📐 **Altura Total** (distância de topo a base)
- 🔹 **Apótema** (ou Raio da Circunferência Inscrita)
- 🔹 **Raio da Circunferência Circunscrita**
- 🔹 **Perímetro** e **Área**
- 🔹 **Diagonal Máxima** e **Total de Diagonais**
- 🔸 **Ângulos**: Interno, Externo e Central

## 🚀 Como Executar

### Pré-requisitos
* **Python 3.x** instalado.
* Utiliza apenas a biblioteca padrão `math` (sem necessidade de instalar pacotes externos).

### Executando no Terminal
1. Baixe ou salve o arquivo do código (ex: `polígono.py`).
2. Abra o terminal na pasta do arquivo e execute:

```bash
python poligono.py
